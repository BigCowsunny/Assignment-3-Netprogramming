# NetSmonitor logo

Generated with the built-in imagegen tool. Transparent PNG used in the application header and browser favicon.

Final asset: `src/assets/netsmonitor-logo.png`. Imported by the header and referenced by the HTML favicon so Vite includes it in the build with a content hash for cache invalidation. The original generated PNG is also retained in `public/branding/netsmonitor-logo.png`.

## Generation prompt

Use case: logo-brand. Asset type: production app logo symbol for NetSmonitor, an enterprise SNMP network monitoring web application. Create one original, polished geometric N monogram formed by two connected network paths, with one compact teal node suggesting an active network signal. Style: precise flat vector-like geometry, strong simple silhouette, confident and understated enterprise identity. Palette: royal blue #245edb with a small teal #1396a5 accent, suitable on a white application header. Composition: a single large centered square symbol occupying about 85% of the canvas with narrow balanced transparent margins; ensure it reads clearly at 34px. Actual transparent background, crisp edges. Symbol only, no wordmark, no text, no mockup, no badge background, no gradients, no shadows, no 3D, no watermark. The application already renders the name NetSmonitor next to the symbol.
