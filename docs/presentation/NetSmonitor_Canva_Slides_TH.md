## 1. NetSmonitor

ระบบติดตามและจัดการอุปกรณ์เครือข่ายด้วย SNMP

- สรุปฟังก์ชันการทำงานของโปรแกรม
- Assignment 3 · Network Programming


## 2. ภาพรวมการทำงาน

- React + TypeScript แสดงผลบนเว็บ
- FastAPI ติดต่อ Router / Switch ผ่าน SNMPv2c
- SQLite เก็บอุปกรณ์ ทราฟฟิก และเหตุการณ์
- WebSocket ส่งเหตุการณ์และสถานะที่เปลี่ยน


## 3. Dashboard ดูภาพรวมเครือข่าย

- ดูจำนวนอุปกรณ์ออนไลน์และพอร์ตที่ใช้งาน
- สรุปเหตุการณ์ Link ใน 24 ชั่วโมง
- ดูทราฟฟิกรวมและโหลดจากข้อมูลล่าสุด
- เลือกพอร์ตที่ใช้งานสูงสุดเพื่อเปิดกราฟ


## 4. จัดการรายการอุปกรณ์

- เพิ่มด้วย IP, Community และ UDP port
- Test Connection และอ่าน IF-MIB ก่อนบันทึก
- ค้นหาและกรองตามประเภทหรือสถานะ
- แก้ไขการเชื่อมต่อ หรือลบออกจากระบบ


## 5. รายละเอียดอุปกรณ์และพอร์ต

- แสดงชื่อ รุ่น IP และ Uptime
- ดูรายการพอร์ตและภาพแสดงพอร์ต
- แยก Admin Status กับ Oper Status
- เลือกพอร์ตเพื่อดู Traffic หรือสั่งงาน


## 6. เปิด–ปิดพอร์ตด้วย SNMP SET

- เลือก Interface และยืนยันคำสั่ง Up / Down
- ส่ง ifAdminStatus ค่า 1 = up หรือ 2 = down
- อ่านค่ากลับเพื่อยืนยันผลจากอุปกรณ์
- บันทึก Audit และแจ้งหน้าเว็บผ่าน WebSocket

เงื่อนไข: ต้องมีสิทธิ์เขียน OID ของพอร์ต และ Admin up ยังไม่รับรองว่า Oper up


## 7. Traffic รับ–ส่งและกราฟย้อนหลัง

- อ่าน Octet counters แล้วคำนวณอัตรา In / Out เป็น bps
- เลือกช่วง Live, วัน, สัปดาห์, เดือน หรือปี
- ดูค่าปัจจุบัน ต่ำสุด สูงสุด และเฉลี่ย
- ส่งออกข้อมูล CSV หรือรูปกราฟ PNG

เงื่อนไข: เริ่มคำนวณเมื่อมี counter อย่างน้อย 2 รอบ และแสดงย้อนหลังเท่าที่เก็บจริง


## 8. เหตุการณ์ Link Up / Link Down

- รับ SNMP Trap จากอุปกรณ์ผ่าน UDP
- จับคู่ Source IP และ ifIndex กับพอร์ต
- เก็บเหตุการณ์และส่ง TRAP_EVENT ผ่าน WebSocket
- ค้นหาและกรองเหตุการณ์ตามอุปกรณ์หรือประเภท

เงื่อนไข: อุปกรณ์ต้องตั้งปลายทาง Trap ให้ถึง Backend


## 9. Auto Discovery ด้วย CDP / LLDP

- เริ่มจาก Seed IP หรืออุปกรณ์ที่บันทึกไว้
- อ่าน Neighbor ผ่าน SNMP แล้วค้นต่อจาก IP ที่พบ
- รับประกาศ CDP / LLDP ที่มาถึง NIC ของ Backend
- แสดงอุปกรณ์ไม่มี IP และยืนยัน SNMP ภายหลังได้

เงื่อนไข: อุปกรณ์ไม่มี IP หรือยังไม่ยืนยัน SNMP ใช้ Config และ Traffic ไม่ได้


## 10. Topology แสดงความสัมพันธ์ของอุปกรณ์

- สร้าง Node และสายจาก CDP / LLDP Neighbor
- แสดงชื่อพอร์ตทั้งสองฝั่งและลดรายงานซ้ำ
- ลากจัดตำแหน่งและคลิก Node ดูรายละเอียด
- อัปเดตข้อมูลเมื่อค้นหาใหม่หรือข้อมูลหมดอายุ

เงื่อนไข: Topology อ้างอิง Neighbor ที่อุปกรณ์รายงาน และอาจเห็นได้ไม่ครบทุกสาย


## 11. ตั้งค่าระบบและตรวจสอบ Audit

- ปรับรอบ SNMP Polling ได้ 10–3,600 วินาที
- เก็บค่าตั้งไว้และใช้หลังรีสตาร์ตระบบ
- ตรวจสถานะ API, Poller และพอร์ต Trap Receiver
- ค้นหาประวัติคำสั่งและผลการดำเนินการ


## 12. ลำดับสาธิตโปรแกรม

- 1  ตรวจสถานะบริการ แล้วเปิด Dashboard
- 2  เลือกอุปกรณ์และอธิบาย Admin / Oper
- 3  เปิดกราฟ Traffic และลองส่งออก CSV
- 4  ดู Events แล้วคลิก Node บน Topology

เงื่อนไข: สาธิต Up / Down เพิ่มได้เมื่อเตรียมพอร์ตทดสอบไว้


## 13. สรุปความสามารถและเงื่อนไขใช้งาน

- ตรวจสถานะอุปกรณ์และวิเคราะห์ Traffic
- ควบคุมพอร์ต พร้อมอ่านผลกลับและเก็บ Audit
- รับ Trap และสร้าง Topology จาก Neighbor
- ใช้งานได้เมื่อ IP, SNMP และเส้นทาง Trap พร้อม

เงื่อนไข: Monitoring ใช้ SNMPv2c และข้อมูลย้อนหลังขึ้นกับระยะเวลาที่เก็บ
